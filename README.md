# 🩺 AI Geeks — Diabetes Prediction

A Python ML classification project that predicts whether a patient is likely to have diabetes based on health metrics.  
Built as part of the **AI Geeks** community learning program.

---

## 🧠 What It Does

- Loads the Pima Indians Diabetes Dataset (standard benchmark)
- Preprocesses and scales health features
- Trains a classification model (Logistic Regression / Random Forest)
- Evaluates accuracy, precision, and recall
- Outputs a prediction: diabetic or non-diabetic

---

## 🚀 How to Run

```bash
git clone https://github.com/theprasunbanerjee/AI-Geeks-Diabetes-Prediction.git
cd AI-Geeks-Diabetes-Prediction

pip install -r requirements.txt
jupyter notebook
```

---

## 📋 Features Used

| Feature | Description |
|---|---|
| Pregnancies | Number of pregnancies |
| Glucose | Plasma glucose concentration |
| BloodPressure | Diastolic blood pressure (mm Hg) |
| BMI | Body mass index |
| DiabetesPedigreeFunction | Genetic diabetes risk score |
| Age | Age in years |
